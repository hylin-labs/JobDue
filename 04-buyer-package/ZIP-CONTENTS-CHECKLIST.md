# ZIP Contents Checklist

Use this checklist before uploading `JobDue-Buyer-Package.zip`.

## Customer Files

- [ ] `JobDue.html` - buyer-facing browser app
- [ ] `README-FIRST.pdf` - one-minute start guide
- [ ] `BACKUP-GUIDE.pdf` - backup, restore, and device-transfer guide
- [ ] `TROUBLESHOOTING.pdf` - common opening and browser issues
- [ ] `iPhone-iPad-Setup-Video.mp4` - iPhone/iPad setup video
- [ ] `Android-Setup-Video.mp4` - Android phone/tablet setup video
- [ ] `LICENSE.txt` - personal/small-business license
- [ ] `sample-backup.json` - optional sample data for testing
- [ ] `buyer-only-phone-tablet-install-link.txt` - hosted phone/tablet install link

## Do Not Include

- [ ] Developer screenshots or design drafts
- [ ] Source Markdown files if the customer ZIP is PDF-only
- [ ] Remotion project files
- [ ] Playwright scripts
- [ ] Git or build folders

## Final Checks

- [ ] Open `JobDue.html` from the ZIP.
- [ ] Add one test job.
- [ ] Export a JSON backup.
- [ ] Import a valid backup and confirm preview appears.
- [ ] Confirm `README-FIRST.pdf` includes `https://app.hi-craniai.workers.dev`.
- [ ] Confirm docs say no login, no subscription, no cloud sync, no invoice sending, and no payment processing.
