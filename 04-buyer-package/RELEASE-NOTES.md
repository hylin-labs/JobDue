# Release Notes

## JobDue V1

JobDue is a browser-based job, payment, follow-up, and review-request tracker for solo contractors and small home-service operators.

## What Is Included

- One-file browser app for desktop/laptop use
- Hosted phone/tablet install link
- Today, Jobs, Money, and Data views
- Local browser save
- JSON backup export and import
- CSV export for spreadsheet review
- Sample data
- Quick-start, backup, troubleshooting, license, and setup videos

## Important Limits

JobDue V1 does not include:

- Login accounts
- Subscriptions
- Automatic cloud sync
- Invoice sending
- Payment processing
- QuickBooks integration
- Team dispatch
- Native desktop or mobile app

## Backup Reminder

Your jobs are saved in the browser/device where you use JobDue. Use **Export Backup** to create a portable `.json` file before switching devices, clearing browser data, or relying on JobDue for regular work.
