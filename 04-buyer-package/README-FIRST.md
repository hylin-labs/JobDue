# Start Here

Thank you for buying JobDue.

JobDue is a simple browser app for tracking contractor jobs, payments, follow-ups, and review requests.

No login. No subscription. No cloud account. No payment processing.

## Desktop Setup

1. Unzip the downloaded ZIP file.
2. Open `JobDue.html` or `index.html` in Chrome, Edge, or Safari.
3. Choose **Use Sample Data**, **Start Blank**, or **Import Backup**.
4. Add or edit one job.
5. Check Today, Jobs, and Money.
6. Go to Data and click **Export Backup**.

Do not use private/incognito mode for real work. Private windows may not keep saved jobs.

If the file does not open, right-click `JobDue.html`, choose **Open with**, then choose Chrome, Edge, or Safari.

## Backups Matter

Jobs entered on the hosted phone/tablet app do not automatically appear in the desktop file unless you use Export Backup and Import Backup.

That means jobs do not automatically sync between desktop, phone, tablet, or different browsers.

Use **Data > Export Backup** to create a portable `.json` backup file.

Use **Import Backup** to restore or move jobs to another device.

CSV export is for spreadsheet review only. CSV files do not restore JobDue.

## What JobDue Does Not Do

JobDue does not include:

- Automatic cloud sync
- Invoice sending
- Payment processing
- QuickBooks integration
- Team dispatch
- Login accounts
- Subscriptions

For more help, open `BACKUP-GUIDE.pdf` or `TROUBLESHOOTING.pdf`.
