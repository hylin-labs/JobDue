# Changelog

## JobDue V1 - 2026-05-12

- Added buyer-facing JobDue app package.
- Added quick-start, backup, troubleshooting, and license documents.
- Added iPhone/iPad and Android setup videos.
- Added hosted phone/tablet install link.
- Added sample backup file for demo/testing.
- Clarified that JobDue saves data in the current browser/device.
- Clarified that Export Backup and Import Backup are required to move or restore data.
- Clarified unsupported features: no login, no subscription, no cloud sync, no invoice sending, no payment processing, no QuickBooks integration, and no team dispatch.
