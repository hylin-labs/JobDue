Backup and data

Your jobs are saved in this browser/device.

Export Backup creates a portable JSON file.

Use it for recovery or device transfer.

Import Backup moves or restores your jobs.

JobDue previews the file before replacing current jobs.

CSV export is for spreadsheet review, not full restore.

Use JSON backup when you need to recover the app.

Cloud drives can store backup files.

They do not sync the app automatically.
