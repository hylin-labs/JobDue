# JobDue App/PWA Workspace

This folder is an isolated rebrand copy of the original app. The original source files are not modified.

- `JobDue.html` is the buyer-facing offline browser app.
- `index.html` is the hosted/PWA entry copy.
- `manifest.webmanifest`, `service-worker.js`, and `assets/` use JobDue branding.
- Browser storage keys intentionally remain `contractorTracker.v1` and `contractorTracker.demo.v1` so old backups and saved records stay compatible.
