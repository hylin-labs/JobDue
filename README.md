# JobDue

JobDue is a no-login, one-time-purchase browser tracker for solo contractors.

**Track jobs. Follow up. Get paid.**

This repository is the clean JobDue publication tree. It contains the rebranded app/PWA, landing page, buyer package, listing assets, videos, and release checks. The original CollectDesk checkout remains outside this publication tree and is not modified by this package.

## Main folders

- `02-app-pwa/` - JobDue browser app and PWA files
- `03-landing/` - static landing page and product guide
- `04-buyer-package/` - buyer download package and setup documentation
- `05-listing-assets/` - listing graphics and screenshots
- `06-video/` - JobDue-branded product and setup videos
- `07-release-checks/` - QA, audit, and release evidence

## Product boundaries

JobDue stores records locally in the browser/device and supports backup export/import. It is not accounting software, a cloud-sync service, a payment processor, or a team dispatch system.
